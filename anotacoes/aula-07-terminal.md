## 💻 Aula 07: Prompt de Comando | PowerShell | Terminal

- Interfaces de **linha de comando** para executar ordens diretas ao sistema operacional sem usar a interface gráfica.
- É como **falar diretamente com o motorista**: em vez de apontar o mapa, você dá a ordem exata em texto.

### 🛠️ Prática Realizada

1. Abertura do **Terminal do Windows** como Administrador.
2. Execução de comandos básicos de navegação de pastas (`dir`, `cd`).
3. Verificação de conectividade de rede através do comando `ping`.

### ⌨️ Atalhos

| Atalho                     | Ação                                              |
| :------------------------- | :------------------------------------------------ |
| `Win` + `X`                | Abre o menu de links rápidos de sistema           |
| `Ctrl` + `Shift` + `Enter` | Executa o programa selecionado como Administrador |
