## 👥 Aula 09: Contas de Usuário

- Gerenciamento de perfis de uso com **permissões de acesso**, **senhas** e **privacidade separadas**.
- É como **dar uma chave diferente para cada morador da casa**: cada um tem seu próprio quarto (espaço) e regras.

### 🛠️ Prática Realizada

1. Criação de uma conta de usuário local sem privilégios administrativos.
2. Alteração de **métodos de entrada** (PIN, Senha, Biometria).
3. Troca rápida entre perfis de usuários ativos.

### ⌨️ Atalhos

| Atalho      | Ação                                         |
| :---------- | :------------------------------------------- |
| `Win` + `L` | Bloqueia a tela/conta atual instantaneamente |
