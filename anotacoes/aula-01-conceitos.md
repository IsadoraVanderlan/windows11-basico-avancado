## 💻 Aula 01: Conhecendo o Sistema Operacional

- É o **software principal** que gerencia todo o hardware do computador (memória, processador, disco).
- Funciona como o **maestro de uma orquestra**: coordena todos os programas para que funcionem sem conflito.

### 🛠️ Prática Realizada

1. Exploração do novo layout do **Menu Iniciar** e dos aplicativos fixados.
2. Manipulação de janelas (**abrir, maximizar, minimizar e fechar**).
3. Organização inicial de ícones na **Área de Trabalho**.

### ⌨️ Atalhos

| Atalho        | Ação                                         |
| :------------ | :------------------------------------------- |
| `Win`         | Abre o Menu Iniciar                          |
| `Alt` + `Tab` | Alterna rapidamente entre as janelas abertas |
| `Win` + `D`   | Minimiza tudo e mostra a Área de Trabalho    |
