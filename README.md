# 💻 Windows 11 - Do Básico ao Avançado

Este repositório foi criado para documentar todo o meu progresso, anotações e aprendizados práticos durante o curso de Windows 11.

## 🎯 Objetivos

- Dominar a interface e a produtividade no Windows 11.
- Aprender conceitos de administração de sistemas (usuários, tarefas e serviços).
- Utilizar o terminal (CMD/PowerShell) para automação de tarefas simples.
